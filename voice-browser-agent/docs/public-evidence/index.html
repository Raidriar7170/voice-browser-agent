Voice-to-Browser Agent

standalone bounded spoken-command browser execution evidence with local visual grounding, deterministic safety gates, and sanitized trace artifacts.

Scope

This page is a committed public evidence index. It does not require the Operator Console to run. Generated release packs, demo media, and seed-set outputs stay local unless a sanitized artifact is intentionally committed.

Evidence Modes

Mode Committed Source Purpose
demo_preview fixtures/traces/sanitized/ Stable preview traces for fixture-backed spoken commands.
live_controlled fixtures/traces/live-sanitized/ Local controlled-page execution traces, including the controlled GitHub-like showcase.
agentic_live_controlled fixtures/traces/agentic-sanitized/ Observe-act-verify traces with agentic step evidence.
real_vision_controlled fixtures/traces/real-vision-sanitized/ Controlled icon-search trace produced by calling browser_use_vision.som.annotate_screenshot.
real_voice_controlled fixtures/traces/real-voice-sanitized/ Reviewed audio input, ASR metadata, controlled local browser execution, and sanitized grounding evidence.
real_use_failure fixtures/traces/real-use-sanitized/ ASR unavailable, clarification, confirmation, cancellation, and ambiguous-target traces as reliability evidence.
live_public_readonly local private runtime traces until sanitized Allowlisted public read-only pages only; task-contract match and completion verifier required; No login, no mutation, private-by-default evidence.

The public-readonly reliability matrix is a summary layer over the smoke set, not a public raw trace dump. It reports completed, partial, stopped, failed, and blocked rows with target class, completion criteria, proof summary, reason, privacy state, sanitizer status, and export state.

Route-Aware Console Flow

Operator Console v3 records a route_decision for command-first runs. GitHub-shaped commands can route to demo/pages/github_showcase.html as controlled local evidence when real public-readonly is disabled. Real GitHub public-readonly execution remains disabled by default unless an allowlist and matching github-repo-search or github-public-repo-read task contract are configured for live_public_readonly. Public tasks that only open a page are shown as incomplete, stopped, failed, or blocked until the completion verifier observes task-specific proof. Real GitHub screenshots are visible in the local Operator Console but remain local/private unless a sanitizer-approved trace exists.

Demo Media Contract

The 60-90 second demo contract is defined in docs/demo/video-plan.md. It shows transcript or fixture input, real audio review, normalization, safety gate behavior, controlled visual execution, sanitized trace export, release-pack inspection, and seed-set inspection.

Seed-Set Workflow

The seed-set workflow combines trace-derived examples with reviewed variants from fixtures/seed-set/reviewed-variants.json. The generated manifest records source trace id, evidence mode, variant status, and privacy-scan status for each example.

limitations

The artifacts are small, local, privacy-gated project evidence. They do not include model training, model checkpoints, raw recordings, raw screenshots, browser profiles, credentials, private URLs, remote host details, broad public-web autonomy claims, or write-capable public-site actions.
