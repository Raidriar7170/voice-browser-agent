Voice-to-Browser Agent

Reliable voice-driven browser execution with visual grounding, deterministic safety gates, and traceable evidence for a bounded Chinese-first spoken-command workflow.

Problem Framing

This standalone project asks a narrow reliability question: can one spoken browser command become one structured browser task, pass deterministic checks, execute with visual grounding, and leave enough evidence for a reviewer to understand what happened?

The answer is represented in code, tests, OpenSpec specs, sanitized traces, a release-pack workflow, a public evidence page, and a local Speech-to-Task adaptation seed set.

Bounded Scope

The system supports one utterance at a time. It normalizes the transcript into a Browser Task Request or Clarification Request, applies safety checks, and runs either preview, live-controlled, agentic live-controlled, or real-vision controlled evidence paths.

Architecture

Input and ASR

Uploaded, recorded, or fixture-backed audio produces an auditable transcript record.

Normalizer and Validator

Transcript text becomes a structured task or a clarification stop before execution.

Browser Execution

The executor runs bounded local browser tasks and records actions, statuses, and stops.

Visual Grounding

browser-use-vision remains the visual grounding dependency; this standalone repo owns voice-to-task flow.

Execution Flow

  1. One spoken command is accepted through upload, recording, transcript, or fixture replay.
  2. The ASR adapter or fixture manifest creates transcript metadata.
  3. The Spoken Command Normalizer creates a task request or clarification request.
  4. The Normalizer Validator and Confirmation Gate block unsafe or ambiguous actions.
  5. The executor records browser actions, agentic steps, final status, and sanitized evidence.

Evidence Modes

  • demo_preview: stable public showcase evidence without live page execution.
  • live_controlled: selected local controlled visual tasks with action evidence.
  • agentic_live_controlled: observe-act-verify traces with agentic step evidence.
  • real_vision_controlled: controlled icon-search evidence that calls browser_use_vision.som.annotate_screenshot.

Committed trace sources live in fixtures/traces/sanitized/, fixtures/traces/live-sanitized/, and fixtures/traces/agentic-sanitized/, and fixtures/traces/real-vision-sanitized/.

Safety and Privacy Gates

The project rejects unsupported long-horizon intents, pauses sensitive actions at the Confirmation Gate, and keeps raw recordings, live browser state, generated runtime outputs, and private operational details out of committed artifacts.

Review the safety behavior through docs/demo/ablations.md, docs/demo/demo-task-suite.md, and the sanitized trace folders.

Limitations

Model fine-tuning, expanded dataset collection, public hosting, broad public-web automation, and model checkpoint release are outside this closeout MVP.

The contribution is the bounded, evidence-backed voice-to-browser execution stack and its reviewer artifacts.
